# Jogo da Velha

Jogo da Velha multiplayer desenvolvido como projeto prático para estudo de comunicação em tempo real com Socket.IO.

🌐 [https://jogo-da-velha.fun](https://jogo-da-velha.fun)

## Tecnologias

- Node.js
- Express
- Socket.IO
- JavaScript
- HTML
- CSS

## Arquitetura

Frontend e backend separados.
As partidas são mantidas temporariamente em memória
e removidas quando os jogadores se desconectam.

## Objetivo

Projeto desenvolvido para aprendizado prático de
comunicação em tempo real e desenvolvimento web.
